# Documentos descargables

Fichas técnicas, certificados CE, IFU (instrucciones de uso) y documentos de política, en PDF.

- **Nombre de archivo**: `{slug-del-producto}-ficha-tecnica.pdf`, `{slug-del-producto}-certificado-ce.pdf`, etc. Ej: `reactivos-abiertos-ficha-tecnica.pdf`.
- **Política de la empresa**: `politica-empresa.pdf` — va enlazada desde `politicas.html`.

Cuando subas PDFs acá, avísame para enlazarlos desde la sección "Documentos" de cada ficha de producto y desde `politicas.html`.
