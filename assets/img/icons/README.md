# Logos de marcas / iconografía raster

Para logos de marcas representadas (ej. reemplazar los `.brand-chip` de texto en "Marcas representadas" por logos reales) u otro ícono que no convenga como SVG inline.

- **Formato**: SVG si es posible (se ve nítido a cualquier tamaño); si no, PNG con fondo transparente.
- **Nombre de archivo**: nombre de la marca en minúscula, ej. `sansure-biotech.svg`.
- **Tamaño**: si es PNG, exportar a 2x (ej. logo de 160px de alto → archivo de 320px) para pantallas retina.
