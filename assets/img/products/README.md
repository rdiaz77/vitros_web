# Fotos de producto

Fotos reales de cada test/reactivo (reemplazan los íconos SVG placeholder).

- **Nombre de archivo**: usa el mismo slug de la URL del producto, ej. `reactivos-abiertos-1.jpg`, `reactivos-abiertos-2.jpg` para la galería.
- **Formato**: JPG o WebP.
- **Tamaño**: mínimo 1200×1200px (cuadrado o 4:3), fondo limpio/blanco si es foto de empaque.
- **Peso**: idealmente bajo 300 KB por imagen (comprimida).

Una vez que subas fotos acá, avísame para cablearlas en la ficha de cada producto (`producto.html`, `producto-reactivos-abiertos.html`, y las páginas `categoria-*.html`).
